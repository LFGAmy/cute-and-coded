## what it is

A place your files and context live outside any single chat, so a new conversation never starts from zero.

## why you'd want it

Because re-explaining the same background every single time is the tax you're currently paying.

## steal this

New project → name it after the one thing you're working on → drop in the files you keep re-uploading.
